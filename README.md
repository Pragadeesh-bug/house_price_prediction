# 🏠 House Price Prediction using XGBoost Regressor

## 📌 Project Overview

This project predicts the price of a house based on its features such as area, number of bedrooms, bathrooms, floors, house age, and parking spaces.

The project uses **XGBoost Regressor**, a powerful machine learning algorithm for regression problems.

The model learns patterns from existing house-price data and uses those patterns to predict the price of a new house.

---

## 🎯 Objective

The main objective of this project is to:

- Predict house prices using Machine Learning.
- Understand how different house features affect price.
- Use XGBoost Regressor for regression.
- Evaluate the performance of the trained model.
- Allow users to enter house details and get a predicted price.

---

## 🧠 Machine Learning Algorithm

### XGBoost Regressor

**XGBoost** stands for **Extreme Gradient Boosting**.

It is an ensemble machine learning algorithm that uses multiple decision trees to make accurate predictions.

In this project:

```text
House Features
      ↓
XGBoost Regressor
      ↓
Predicted House Price
```

## 📈 Model Evaluation

The model is evaluated using the following metrics:

### Mean Absolute Error (MAE)

Measures the average difference between the actual and predicted prices.

Lower MAE is better.

### Mean Squared Error (MSE)

Measures the squared difference between actual and predicted values.

Lower MSE is better.

### Root Mean Squared Error (RMSE)

RMSE is the square root of MSE.

Lower RMSE indicates better performance.

### R² Score

R² indicates how well the model explains the variation in house prices.

A value closer to **1.0** generally indicates better performance.
